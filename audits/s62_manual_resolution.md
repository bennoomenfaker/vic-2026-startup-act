# Résolution manuelle de S62 — 05/2024

## Conclusion

Le compteur publié par Startup Tunisia est de **39 candidatures officielles**. Le PDF contient **46 lignes documentaires**. Ces deux valeurs ne mesurent pas la même unité et ne doivent pas être forcées à l’égalité.

La réconciliation est :

| Composant | Nombre | Traitement |
|---|---:|---|
| Labels accordés au premier examen | 9 | Candidatures officielles |
| Prélabels accordés | 5 | Candidatures officielles |
| Labels non accordés | 7 | Candidatures officielles |
| Prélabels non accordés | 14 | Candidatures officielles |
| Dossiers sans décision publiée, motif administratif | 4 | Candidatures officielles, statut séparé |
| **Total candidatures officielles** | **39** | **9 + 5 + 7 + 14 + 4** |
| Conversions Prélabel → Label | 5 | Lignes documentaires supplémentaires |
| Retraits de Label | 2 | Lignes documentaires supplémentaires |
| **Total lignes documentaires** | **46** | **39 + 5 + 2** |

Les **14 Labels accordés** visibles dans le registre détaillé comprennent les **9 Labels accordés au premier examen** et les **5 conversions**. Les quatre dossiers administratifs ne sont ni « Reporté » ni « Label non accordé » : ils sont maintenant classés **« Décision non précisée — motif administratif »**.

## Règle d’interprétation

Le compteur **39** est conservé comme compteur officiel Startup Tunisia. Le nombre **46** est conservé comme nombre de lignes documentaires extraites du PDF. Le dashboard affiche ces deux valeurs séparément et explique l’écart dans la page **Corrections**. Les quatre motifs administratifs sont conservés dans JSON, CSV, SQL, SQLite et la table détaillée du site.
