# Constats visuels validés

Le graphique géographique 2019–2021 est lisible : Grand Tunis domine nettement, tandis que Centre-Est progresse en 2021. Les libellés régionaux ont été harmonisés uniquement pour comparer les trois rapports ; les valeurs originales et les différences de nomenclature sont conservées dans le CSV.

Le graphique annuel montre un pic des candidatures en 2021, puis un recul en 2026 qui s’explique par une année partielle couvrant trois sessions. Les courbes Labels et Prélabels sont distinguées ; aucune interprétation de causalité ne doit être tirée de la seule figure.
