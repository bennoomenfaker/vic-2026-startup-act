# **7. Bibliographie**

## **Sources officielles**
1. **Loi n° 2018-20 du 17 avril 2018** – Startup Act tunisien.
   - [Lien vers le texte officiel](https://www.legislation.tn) (à vérifier).
2. **Site officiel startup.gov.tn** – Tableau `/sessions`.
   - [https://startup.gov.tn/sessions](https://startup.gov.tn/sessions).
3. **PDF officiels des 85 sessions** – Comptes rendus de labellisation.
   - Disponibles dans `public/data/session-pdfs/`.

## **Outils et technologies**
1. **Python** – Langage de programmation pour le parsing et l’analyse.
   - Librairies : `PyPDF2`, `pandas`, `json`.
2. **Chart.js** – Bibliothèque JavaScript pour les graphiques interactifs.
   - [https://www.chartjs.org/](https://www.chartjs.org/).
3. **Leaflet** – Bibliothèque JavaScript pour les cartes interactives.
   - [https://leafletjs.com/](https://leafletjs.com/).
4. **Git/GitHub** – Versionnage et collaboration.
   - [https://github.com/](https://github.com/).
